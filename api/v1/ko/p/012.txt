Motion Prompt #012

어떤 것인가: 한 도형이 다른 도형으로 부드럽게 바뀐다
견본에서 일어나는 일: 원 → 사각형 → 별 → 하트로 모양과 색이 부드럽게 바뀐다.
사양:
- 도형 4개, 각 1.175초: 원 → 모서리를 둥글게 깎은 사각형 → 별 → 하트 → 다시 원. 기준 반지름 64.
- 각 구간은 먼저 멈춰 있다가, 끝나기 0.62초 전부터 0.04초 전까지(0.58초) 다음 도형으로 변형된다.
- 각 외곽선은 점 240개로 저장하고, 같은 번호의 점끼리 선형 보간한다. 진행도는 backOut(s = 1.6)이라 살짝 오버슈트한다.
- 색: 파랑 → 코랄 → 노랑 → 민트. 2차 easeInOut으로 섞는다.
- 변형 중에는 스케일이 1 + 0.07 × sin(π × 진행도)만큼 부푼다.
- 아래에 점 4개. 현재 도형의 점이 더 크고 색이 들어간다.
쓰임새: 아이콘이나 로고를 컷 없이 다른 모양으로 바꿀 때.
