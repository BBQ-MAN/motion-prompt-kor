Motion Prompt #161

어떤 것인가: 목록 사진이 그대로 상세 화면으로 커진다
견본에서 일어나는 일: 목록의 사진을 누르면 그 사진이 그대로 상세 페이지 상단 이미지로 커지고 나머지는 상세 페이지로 바뀐다. 뒤로 가면 사진이 제자리로 줄어든다.
사양:
- 511 × 168 뷰포트, 목록에 사진 3장(143 × 80, radius 6). 0.75초에 가운데 사진이 클릭되고, 3.05초에 상세 페이지의 "← 一覧へ"(목록으로)가 클릭된다. 1회 4.7초(팩 주기 9.4초에 2회).
- 앞으로: 0.85–1.45초(0.6초, cubic ease-in-out)에 클릭한 사진이 목록 자리에서 상세 페이지 상단의 479 × 94 이미지(radius 8)까지 연속으로 이동하며 크기가 바뀐다. 처음부터 끝까지 한 장의 사진이다.
- 다른 사진과 제목은 이동의 처음 62% 동안 페이드아웃되고, 상세 제목, 본문, 뒤로 버튼은 마지막 40% 동안 페이드인된다. 50% 시점에 URL이 /works에서 /works/02로 바뀐다.
- 뒤로: 3.15–3.75초(0.6초)에 같은 움직임이 거꾸로 진행되어 목록 자리로 돌아간다.
- 목록 사진과 상세 사진이 같은 view-transition-name을 공유할 때 View Transitions API가 보여 주는 모습이다.
쓰임새: 목록과 상세를 오가는 갤러리나 상품 페이지에서 무엇을 열었는지 놓치지 않게 할 때.
