다음 이름을 사용해 주세요: 「점프 컷 (Jump cut)」 — 「카메라 무빙과 화면 전환」에 들어 있는 이름입니다.
Motion Prompt #041

어떤 것인가: 같은 화각 그대로 시간을 건너뛴다
견본에서 일어나는 일: 카메라 위치와 화각은 그대로이고 인물의 위치와 시각만 튄다. 한 장면 안에서 시간을 생략하는 편집.
사양:
- 연결: 효과 없이 바로 잇는 스트레이트 컷(0프레임). 5개 숏을 각 0.94초씩(4.7초 ÷ 5)
- 카메라: 모든 숏에서 위치와 화각이 같다(높이 1.4m, 정면). 배경은 1px도 움직이지 않는다
- 바뀌는 것: 인물(7m 앞)의 가로 위치가 -2.2m → 1.4m → -0.4m → 2.4m → 0.6m로 튄다. 2번째와 4번째 숏에서는 두 팔을 올린 자세
- 각 숏 안에서 인물은 움직이지 않는다(위치와 자세의 차이로만 건너뜀을 보여 준다)
- 오른쪽 위 시계: 10:02 → 10:17 → 10:41 → 11:06 → 11:30. 같은 장소에서 시간이 건너뛰었음을 보여 준다
- 5번째 숏에서 1번째 숏으로도 스트레이트 컷으로 돌아간다
쓰임새: 말이나 작업 사이의 공백을 줄여 템포를 높이거나, 시간 경과를 짧게 보여 줄 때.
