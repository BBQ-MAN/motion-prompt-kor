다음 이름을 사용해 주세요: 「더치 앵글 (Dutch angle)」 — 「카메라 무빙과 화면 전환」에 들어 있는 이름입니다.
Motion Prompt #036

어떤 것인가: 화면을 비스듬하게 기울인다
견본에서 일어나는 일: 수평이던 카메라를 렌즈 축을 중심으로 기울여, 지평선이 비스듬한 상태로 멈춘다.
사양:
- 카메라: 위치 고정(높이 1.5m). 롤만 0 → 0.36rad(약 21°). 화면 중앙을 축으로 전체가 회전
- 시간: 0.6초부터 2.2초까지 1.6초. 3차 ease-in-out(cubic-bezier(0.65,0,0.35,1) 상당)
- 피사체: 인물은 7m 앞에서 움직이지 않는다. 지평선, 건물, 인물이 모두 같은 각도로 기운다
- 정지: 2.2초부터 4.2초까지 기운 상태를 유지(기울어진 구도 자체를 보여 주는 시간)
- 복귀: 마지막 0.5초 동안 수평인 시작 상태로 크로스페이드(1회 4.7초)
- 오른쪽 위에 각도 표시(∠ 0° → ∠ 21°)
쓰임새: 불안, 긴장, 무언가 어긋난 느낌을 화면으로 표현할 때.
