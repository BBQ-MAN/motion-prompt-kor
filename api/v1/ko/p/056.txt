Motion Prompt #056

어떤 것인가: 구석에 알림이 떴다가 저절로 사라진다
견본에서 일어나는 일: "저장"을 누르면 오른쪽 아래로 어두운 알림이 미끄러져 들어오고, 남은 시간 막대가 다 줄면 오른쪽으로 빠져나간다.
사양:
- 4.5초 주기, 카드 542×191. 커서가 1.0초에 왼쪽 아래 파란 "저장" 버튼(110×36)을 클릭하고 왼쪽 아래로 빠진다.
- 토스트: #26282c, 214×52, 모서리 반경 10. 오른쪽에서 18px, 아래에서 16px 위치로, 1.05–1.4초에 easeOutCubic으로 오른쪽에서 240px 미끄러져 들어온다.
- 안: 파란 원 안의 흰 체크와 흰색 15px 텍스트 "저장했습니다".
- 아래 가장자리의 남은 시간 막대(높이 3)가 1.4–3.2초에 194px에서 0으로 linear하게 줄어든다.
- 퇴장: 3.2–3.55초에 easeInOutCubic으로 오른쪽으로 240px 빠져나간다.
쓰임새: 저장이나 전송 같은 결과를 작업을 멈추지 않고 짧게 알릴 때.
