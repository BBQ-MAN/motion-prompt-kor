다음 이름을 사용해 주세요: 「고정 샷 (Locked-off shot)」 — 「카메라 워크와 화면 전환 2」에 들어 있는 이름입니다.
Motion Prompt #175

어떤 것인가: 카메라는 고정, 피사체만 움직인다
견본에서 일어나는 일: 삼각대에 고정한 카메라 앞을 인물이 가로지르고 뒤로 차가 지나간다. 카메라는 1픽셀도 움직이지 않는다.
사양:
- 카메라: 완전히 고정(높이 1.4m, 정면 방향, 초점 거리 330px). 피사체만 움직인다
- 피사체: 인물이 6.5m 앞을 왼쪽에서 오른쪽으로 일정한 속도로 가로지른다(4.7초에 x = -6.2m → +6.2m). 다리와 팔은 sin(u×7)×0.42rad로 흔들린다
- 회색 차가 15m 거리를 오른쪽에서 왼쪽으로 지나간다(4.7초에 x = +16m → -16m)
- 둘 다 화면 밖에서 시작해 화면 밖에서 끝나므로 4.7초마다 이음매 없이 반복된다
- 왼쪽 아래에 회색 삼각대 마크, 오른쪽 위에 "LOCKED" 표시(#040 프리즈 프레임은 영상의 시간을 멈춘다. 여기서는 시간이 흐르고 카메라만 멈춰 있다)
쓰임새: 대비로 피사체를 돋보이게 할 때, 정점 관찰, 타임랩스나 합성의 바탕 화면이 필요할 때.
