Motion Prompt #098

어떤 것인가: 뒤에서 오는 빛으로 윤곽만 빛나게 한다
견본에서 일어나는 일: 주변이 어두워지고, 좌우 뒤쪽 사선의 조명 2개가 어두운 인물의 머리와 어깨 양옆에만 가는 빛 테두리를 만든다. 오른쪽 아래 배치도에 조명 2개의 위치를 표시한다.
사양:
- 장면 1: 지평선(y 150) 앞에 가슴 위까지 보이는 인물(머리 중심 x 270, y 78, 반지름 29px, 얼굴·머리카락 없음).
- 배경: 밝은 장면 → 어두운 장면(하늘 #2B2D33, 땅 #24252A). 인물 #4D5A75 → #1F2128
- 빛 테두리: 인물과 같은 형태를 앰버 #FFC75A로 좌우 3.5px, 위로 2.5px 어긋나게 2장 만들어 어두운 인물 뒤에 둔다(테두리 폭 3.5px)
- 오른쪽 아래 배치도(66×66px): 위에서 볼 때 조명은 ±135°(좌우 뒤쪽 사선). 오른쪽 위 표시 "±135°"
- 시간: 0.4~1.4초에 효과가 들어오고 4.0초까지 유지된 뒤 4.8초까지 원래대로 돌아간다(1회 5초, 3차 이즈 인 아웃(cubic-bezier(0.65,0,0.35,1) 상당))
쓰임새: 어두운 배경에서 인물이나 제품을 분리해 형태를 또렷하게 보여 줄 때.
