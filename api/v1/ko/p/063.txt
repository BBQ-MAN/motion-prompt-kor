Motion Prompt #063

어떤 것인가: +/− 버튼으로 숫자를 하나씩 바꾼다
견본에서 일어나는 일: +를 세 번 눌러 숫자가 1에서 4로 늘고, −를 세 번 눌러 1로 돌아온다. 누를 때마다 숫자가 살짝 튄다.
사양:
- 4.5초 주기, 카드 542×191. (171, 52)에 200×60 상자(모서리 반경 12): 왼쪽 60px에 "−", 오른쪽 60px에 파란 "+", 가운데에 굵은 30px 숫자.
- 클릭: +를 0.9, 1.35, 1.8초(1 → 4), −를 2.8, 3.25, 3.7초(4 → 1).
- 누른 쪽 구역은 각 클릭 0.05초 전부터 0.15초 후까지 연한 파랑이 된다.
- 숫자: 누를 때마다 배율이 0.25초 동안 1.18에서 1로 linear하게 돌아오고, 그동안 파랑이다.
쓰임새: 장바구니 수량이나 인원수처럼 작은 정수를 하나씩 바꾸게 할 때.
