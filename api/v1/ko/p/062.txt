Motion Prompt #062

어떤 것인가: 핸들 두 개로 최소·최대 범위를 고른다
견본에서 일어나는 일: 가격 슬라이더에서 왼쪽 핸들을 오른쪽으로, 오른쪽 핸들을 왼쪽으로 끌어 범위를 좁혔다가 원래대로 돌린다.
사양:
- 4.5초 주기, 카드 542×191. 트랙: x 54–488, 높이 8, y 120. 두 핸들 사이는 파랑. 범위 ¥0–¥10,000.
- 핸들: 흰색, 반경 13, 파란 3px 테두리. 드래그 중에는 반경 15에 반경 24의 연한 파란 후광.
- 하한 핸들: 1.0–1.6초에 0.1 → 0.3(¥1,000 → ¥3,000), 3.55–3.9초에 복귀. 상한 핸들: 2.1–2.6초에 1.0 → 0.8(¥10,000 → ¥8,000), 2.95–3.3초에 복귀. 모두 easeInOutCubic.
- 각 핸들 위에 값 말풍선(높이 28). 드래그 중에는 파란 바탕에 흰 텍스트. 오른쪽 위에 "¥1,000 – ¥10,000" 형태로 범위를 파랑으로 표시하고 ¥100 단위로 갱신한다.
- 커서는 끄는 핸들 위에 붙어 함께 움직인다(누르는 시각 1.0, 2.1, 2.95, 3.55초).
쓰임새: 가격·날짜·크기처럼 최소와 최대로 범위를 정해 걸러 낼 때.
