다음 이름을 사용해 주세요: 「리플 효과 (Ripple effect)」 — 「랜딩 페이지·웹사이트 연출」에 들어 있는 이름입니다.
Motion Prompt #085

어떤 것인가: 누른 자리에서 물결이 퍼짐
견본에서 일어나는 일: 버튼을 누를 때마다 누른 지점을 중심으로 흰 원이 퍼져 버튼 안을 채운 뒤 옅어지며 사라진다.
사양:
- 버튼 280×56(주황색, 모서리 반경 10). 0.7초에 중앙 왼쪽, 2.9초에 중앙 오른쪽을 클릭
- 원의 중심 = 클릭한 지점. 반지름 0 → 클릭 지점에서 가장 먼 버튼 모서리까지의 거리, 0.6초 동안(easeOut 3차)
- 색은 흰색, 불투명도 0.4. 클릭 후 0.3~0.8초에 0까지 옅어진다
- 원은 버튼 모양으로 잘라 낸다(overflow: hidden). 라벨은 원 위에 그린다
쓰임새: 버튼이나 목록 항목을 눌렀다는 것을 그 자리에서 바로 알려 주고 싶을 때.
