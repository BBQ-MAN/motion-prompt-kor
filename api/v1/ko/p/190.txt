Motion Prompt #190

어떤 것인가: 동시에 벌어지는 두 장면을 번갈아 보여 준다
견본에서 일어나는 일: 동시에 벌어지는 두 장면, 달리는 사람과 차가 점점 짧아지는 컷으로 번갈아 나온다.
사양:
- 두 장면은 하나의 시계를 공유한다. A는 달리는 사람(왼쪽 0.3m, 깊이 15m → 4.5m, 다리 u×12), B는 도시의 차(오른쪽 1m, 깊이 17m → 4.5m). 둘 다 4.7초에 걸쳐 다가온다
- 컷: 0 / 1.1 / 2.0 / 2.7 / 3.3 / 3.8 / 4.2 / 4.5초에 A와 B를 스트레이트 컷으로 전환. 샷 길이가 1.1 → 0.9 → 0.7 → 0.6 → 0.5 → 0.4 → 0.3초로 짧아지며 긴장감을 높인다
- 한쪽이 화면에 나오는 동안에도 다른 장면은 계속 진행된다(돌아오면 피사체가 그만큼 움직여 있다)
- 카메라: A는 높이 1.3m 고정, 전경에 말뚝 4개. B는 높이 1.6m, 피치 +0.06rad 고정, 도시와 해
- 하단 바: A(회색)와 B(파랑)가 번갈아 나오는 8구간과 재생 헤드. 마지막 0.3초는 A의 시작으로 크로스페이드
- 오른쪽 위에 "SCENE A" / "SCENE B" 표시
쓰임새: 추격이나 구조처럼 동시에 벌어지는 일 사이에 긴장감을 쌓을 때.
