// 무엇이 일어나는가: 같은 풍경의 색이 어두운 곳은 남색, 밝은 곳은 분홍인 두 색 사이의 범위로만 바뀐다.
// 동작 사양:
//   - 장면 3: 왼쪽에 흉상(머리 중심 x 140, y 82, 반지름 28px), 오른쪽에 언덕·집·나무·해(x 432, y 54, 반지름 15px).
//   - 두 색: 어두운 쪽 #1F2A5C, 밝은 쪽 #FF9FB2
//   - 변환: 각 색의 휘도 L로 t = ((L − 70) / 180)^2.4를 구하고, 두 색을 t로 섞는다(밝은 톤끼리의 차이를 넓힌다)
//   - 시간: 0.4~1.4초에 효과가 들어오고 4.0초까지 유지된 뒤 4.8초까지 원래대로 돌아간다(1회 5초, 3차 이즈 인 아웃(cubic-bezier(0.65,0,0.35,1) 상당))
// 쓰임새: 포스터나 음악 아트워크, SNS 이미지를 브랜드 컬러로 통일할 때.
// 태그: duotone, two-tone, gradient map, color overlay, poster, graphic
// 크기: 539x208 px · 1주기: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/photo.js
// 움직이는 견본: https://showheyohtaki.github.io/motion-prompt/#116
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 20
// デュオトーン: 暗い所を藍、明るい所をピンクの2色だけに置き換える
CELLS[19] = cell((k, u) => {
  const a = env(u);
  const DUO = mapPal(BASE, c => mixc('#1F2A5C', '#FF9FB2', Math.pow(clamp((lum(c) - 70) / (250 - 70)), 2.4)));
  stageLand(k, pal(BASE, DUO, a));
});
