// 무엇이 일어나는가: 카메라가 창이 난 벽을 향해 날아가 창을 통과하고 그 너머 공간으로 빠져나온다.
// 동작 사양:
//   - 카메라: 앞으로 0m → 12.5m 전진(높이 1.3m, 방향 고정). 8m 앞에 창이 있는 벽이 있고 카메라가 그 창을 통과한다
//   - 타이밍: 0.5초부터 3.6초까지 3.1초. 3차 ease-in-out(cubic-bezier(0.65,0,0.35,1)에 가까움)
//   - 벽: 폭 80m, 높이 14m의 연회색 평면에 폭 2.4m, 높이 2.2m의 창(창턱 높이 0.15m). 창 너머로 인물(오른쪽 0.3m, 14.5m 거리), 나무, 건물, 산이 보인다
//   - 통과: 벽은 카메라 0.25m 앞에서부터 그리지 않는다. 그 시점에 창 테두리는 이미 화면 밖(반폭 약 1580px)이므로 보이지 않게 사라진다
//   - 통과 후에는 너머의 공간이 화면을 채우고 카메라는 인물 2m 앞까지 다가간다(#035 FPV 드론 샷은 나무 사이를 계속 누빈다)
//   - 복귀: 3.6~4.2초 정지 후 마지막 0.5초 동안 시작 상태로 크로스페이드. 오른쪽 위에 창까지의 거리 표시("窓まで 8.0m" → "通過", 통과)
// 쓰임새: 오프닝에서 건물 안으로 들어갈 때, 한 장소에서 다른 장소로 한 번에 이동할 때.
// 태그: fly-through, flythrough, through the window, pass through, drone, interior, camera move
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 견본: https://showheyohtaki.github.io/motion-prompt/#176
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 08
// 08 フライスルー: 壁の窓へ向かって飛び、通り抜けて向こうの場所へ出る（#035 FPV は木の間を抜けていく）
CELLS[7] = shot(camCell((k, w, h, p) => {
  const z = lerp(0, 12.5, p), WZ = 8;
  world(k, w, h, cam({ z, y: 1.3 }), {
    buildings: true, person: { x: 0.3, z: 14.5 },
    extra: [[0, 0, WZ, (kk, s) => {   // 窓のあいた壁（偶奇塗り）
      kk.fillStyle = C.g1; kk.beginPath(); kk.rect(-40, 0, 80, 14); kk.rect(-1.2, 0.15, 2.4, 2.2); kk.fill('evenodd');
      kk.strokeStyle = C.g3; kk.lineWidth = 1.6 / s; kk.strokeRect(-1.2, 0.15, 2.4, 2.2);
      kk.strokeStyle = C.g2; kk.lineWidth = 1.2 / s; kk.beginPath(); kk.moveTo(-40, 14); kk.lineTo(40, 14); kk.stroke();
    }]]
  });
}, p => { const d = 8 - lerp(0, 12.5, p); return d > 0 ? `窓まで ${d.toFixed(1)}m` : '通過'; }, 0.5, 3.6));
