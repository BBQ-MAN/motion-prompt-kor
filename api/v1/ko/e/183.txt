// 무엇이 일어나는가: 높은 곳에서 마을 전체를 넓게 보여 준다. 카메라가 천천히 다가가고 왼쪽 아래에 장소 자막이 나타난다.
// 동작 사양:
//   - 카메라: 광각(초점 거리 220px, 16mm로 표시), 높이 4.5m, 피치 -0.06rad. -5m에서 -2.5m로 천천히 푸시 인
//   - 타이밍: 0.3초부터 4.2초까지 3.9초. 3차 ease-in-out(cubic-bezier(0.65,0,0.35,1)에 가까움)
//   - 장면: 30m 거리에 도시 건물 8동, 오른쪽 16m, 36m 거리에 탑, 구름 3개와 산. 왼쪽 1m, 12m 거리의 작은 인물로 스케일을 알 수 있다
//   - 장소 자막: 0.9초부터 1.3초까지 "EXT. CITY – DAY"라고 적힌 흰 카드(158×30px, 왼쪽에 파란 바)가 8px 위로 움직이며 왼쪽 아래에 페이드 인한 뒤 그대로 남는다
//   - 복귀: 마지막 0.5초 동안 시작 상태로 크로스페이드(1회 4.7초). 오른쪽 위에 "16mm WIDE" 표시
// 쓰임새: 장면 첫머리에서 여기가 어디인지 알릴 때, 장소나 시간이 바뀔 때.
// 태그: establishing shot, wide shot, location, opening, scene setting, aerial, framing
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 견본: https://showheyohtaki.github.io/motion-prompt/#183
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 15
// 15 エスタブリッシングショット: 広角・高い位置から街全体を見せる引きの画。ゆっくり寄りながら場所の表示が出る
CELLS[14] = shot(camCell((k, w, h, p, u) => {
  const clouds = [[-30, 20, 110, 2.6], [20, 26, 150, 3.2], [60, 17, 95, 2]];
  world(k, w, h, cam({ f: 220, y: 4.5, pitch: -0.06, z: lerp(-5, -2.5, p) }), { city: true, clouds, tower: [16, 36], person: { x: -1, z: 12 } });
  const a = P(u, 0.9, 1.3);   // 場所の表示（左下）
  if (a > 0) { k.save(); k.globalAlpha = a; k.translate(30, h - 52 + (1 - a) * 8); k.fillStyle = 'rgba(255,255,255,.9)'; rr(k, 0, 0, 158, 30, 6); k.fill(); k.fillStyle = C.blue; k.fillRect(0, 0, 4, 30); txt(k, 'EXT. CITY – DAY', 14, 15.5, `600 14px ${MONO}`, C.ink, 'left', 'middle'); k.restore(); }
}, p => `${mm(220)} WIDE`, 0.3, 4.2));
