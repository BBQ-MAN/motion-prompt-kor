// 팩: camera (카메라 무빙과 화면 전환) · element 16 · 카테고리: 촬영 기법과 시간 연출
// 무엇이 일어나는가: 점프한 인물이 정점에 이른 순간 화면이 멈추고, 1.4초 뒤 같은 프레임에서 다시 이어진다.
// 동작 사양:
//   - 카메라: 완전히 고정(높이 1.3m). 멈추는 것은 영상의 시간
//   - 정지: 1.6초에 멈추고 3.0초에 재개(1.4초간). 영상 시간은 0~1.6초는 정상 속도, 정지 중에는 1.6초 그대로, 재개 후에는 u-1.4
//   - 피사체: 7m 앞 인물의 점프는 영상 시간 0.6~2.6초의 포물선, 정점 1.1m. 정지 시점은 정확히 정점(진행률 50%)
//   - 떨어지는 나뭇잎 9장도 정지 중에는 멈춘다. 잎이 떨어지는 속도는 13 슬로모션의 1.5배
//   - 정지 표시: 두께 5px의 파란 테두리와 아래 중앙의 일시정지 아이콘(68×40px 흰 둥근 사각형에 파란 세로 막대 2개). 0.12초 페이드로 나타나고 사라진다
//   - 오른쪽 위에 정지 중에만 “FREEZE” 표시. 복귀 크로스페이드 없음
// 쓰임새: 결정적인 순간을 강조하거나, 화면을 멈추고 이름이나 자막을 얹을 때.
// 태그: freeze frame, still frame, pause, hold, stop motion, highlight
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 움직이는 견본: https://showheyohtaki.github.io/motion-prompt/#040
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 16
// 16 フリーズフレーム
CELLS[15] = shot((k, w, h, u) => {
  // 跳躍の頂点で 1.4 秒止める
  const tj = u < 1.6 ? u : u < 3.0 ? 1.6 : u - 1.4;   // 実時間→映像時間
  const q = P(tj, 0.6, 2.6);
  const frozen = u >= 1.6 && u < 3.0;
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(tj, 1.5) });
  if (frozen) {
    const a = Math.min(1, (u - 1.6) / 0.12, (3.0 - u) / 0.12);
    k.save(); k.globalAlpha = a; k.strokeStyle = C.blue; k.lineWidth = 5; k.strokeRect(2.5, 2.5, w - 5, h - 5);
    k.fillStyle = 'rgba(255,255,255,.88)'; rr(k, w / 2 - 34, h - 58, 68, 40, 8); k.fill();
    k.fillStyle = C.blue; k.fillRect(w / 2 - 12, h - 49, 8, 22); k.fillRect(w / 2 + 4, h - 49, 8, 22); k.restore();
  }
  return frozen ? 'FREEZE' : '';
});
