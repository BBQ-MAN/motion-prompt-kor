// 무엇이 일어나는가: 원이 인물을 향해 좁아지며 화면이 검게 닫히고, 다음 장면에서 다시 열린다.
// 동작 사양:
//   - 아이리스 아웃: 1.3초부터 2.7초까지(1.4초) 원형 창이 반지름 340px에서 0으로 줄어든다(2차 ease-in-out(cubic-bezier(0.45,0,0.55,1)에 가까움)). 원 바깥은 검정(#141418)
//   - 창의 중심: 현재 화면의 피사체를 화면에 투영한 위치. A에서는 인물의 머리(왼쪽 0.6m, 높이 1.63m, 7m 거리), B에서는 차(오른쪽 1.2m, 높이 0.9m, 9m 거리)
//   - 검정: 2.7~3.1초. 2.9초에 들어오는 화면을 스트레이트 컷으로 바꿔 넣는다
//   - 아이리스 인: 3.1초부터 4.4초까지(1.3초) 들어오는 화면의 피사체를 중심으로 원이 0에서 340px로 커진다
//   - 테두리: 반지름이 1px 이상인 동안 2px 파란 원으로 가장자리를 표시. 두 화면 모두 카메라 고정
//   - 4.7초마다 A→B, B→A를 번갈아 반복(왕복 9.4초). 오른쪽 위에 "IRIS OUT" / "IRIS IN" 표시
// 쓰임새: 무성 영화나 만화풍 엔딩, 장난스러운 장면 구분에.
// 태그: iris out, iris in, iris wipe, circle, old film, cartoon, transition
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 견본: https://showheyohtaki.github.io/motion-prompt/#188
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 20
// 20 アイリスアウト: 人物を中心に丸い窓が閉じて黒になり、次の場面は丸い窓が開いて現れる
CELLS[19] = shot(abCell((k, w, h, u, A, B) => {
  const out = eIOs(P(u, 1.3, 2.7)), inn = eIOs(P(u, 3.1, 4.4));
  const first = u < 2.9, cur = first ? A : B;
  cur(k, w, h);
  // 窓の中心は、いま映っている場面の主役（Aは人物の頭、Bは車）
  const c = cur === sceneA ? proj(cam({ y: 1.4 }), -0.6, 1.63, 7) : proj(cam({ y: 1.6, pitch: 0.1 }), 1.2, 0.9, 9);
  const rad = first ? lerp(340, 0, out) : lerp(0, 340, inn);
  const cx = w / 2 + c.x, cy = h / 2 + c.y;
  if (rad < 339) {
    k.fillStyle = '#141418'; k.beginPath(); k.rect(0, 0, w, h); k.arc(cx, cy, Math.max(0, rad), 0, Math.PI * 2, true); k.fill('evenodd');
    if (rad > 1) { k.strokeStyle = C.blue; k.lineWidth = 2; k.beginPath(); k.arc(cx, cy, rad, 0, 7); k.stroke(); }
  }
}, u => u < 2.9 ? 'IRIS OUT' : 'IRIS IN'));
