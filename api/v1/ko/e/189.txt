// 무엇이 일어나는가: 연사에서 듣고 있는 청중으로 갔다가 돌아온다. 끼워 넣는 것은 다른 피사체다.
// 동작 사양:
//   - 연결: 스트레이트 컷 두 번(0프레임). 1.7초에 다른 피사체로, 3.0초에 원래 장면으로(1.3초 동안 벗어남)
//   - 메인 샷(A): 고정 카메라(높이 1.4m). 5.5m 거리의 인물이 팔다리를 0.45·sin(u×6)rad로 흔들며 말하고, 오른쪽 0.9m에 회색 강연대
//   - 다른 피사체(CUTAWAY): 듣고 있는 청중. 3.1~4.6m 거리의 다섯 명이 파랑과 연한 파랑으로, 두 팔을 들고 |sin(t×9+i)|×5cm로 들썩인다. 배경 없음(다른 장소)
//   - 하단 바: A(회색), 다른 피사체(파랑), A(회색)와 재생 헤드(17 인서트 샷은 같은 장면의 디테일을 보여 준다)
//   - 오른쪽 위에 "SHOT A" → "CUTAWAY" → "SHOT A" 표시. 4.7초에 스트레이트 컷으로 처음으로 돌아간다
// 쓰임새: 반응을 보여 줄 때, 시간 건너뜀이나 잘라 낸 말실수를 가릴 때.
// 태그: cutaway, reaction shot, b-roll, cut away, audience, edit
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 견본: https://showheyohtaki.github.io/motion-prompt/#189
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 21
// 21 カットアウェイ: 話す人物から、別の対象（聞いている客席）へ切り替えて戻る。17 インサートは同じ場面の細部
const CUT = [1.7, 3.0];
CELLS[20] = shot((k, w, h, u) => {
  const away = u >= CUT[0] && u < CUT[1];
  if (!away) world(k, w, h, cam({ y: 1.4 }), { person: { x: 0, z: 5.5, walk: 0.45 * Math.sin(u * 6) }, extra: [[0.9, 0, 5.6, (kk) => { kk.fillStyle = C.g3; kk.fillRect(-0.3, 0, 0.6, 1.1); kk.fillRect(-0.4, 1.05, 0.8, 0.1); }]] });
  else {
    const t = u - CUT[0], ex = [];
    [[-1.6, 3.2], [-0.2, 3.6], [1.3, 3.1], [0.6, 4.4], [-1.1, 4.6]].forEach(([x, z], i) => ex.push([x, 0, z, (kk) => { kk.save(); kk.translate(0, Math.abs(Math.sin(t * 9 + i)) * 0.05); person(kk, 1, { armUp: true, col: i % 2 ? C.blue : C.blueM }); kk.restore(); }]));
    world(k, w, h, cam({ y: 1.6, pitch: -0.08 }), { buildings: false, trees: false, mountains: false, sun: null, extra: ex });
  }
  strip(k, w, h, [[0, CUT[0], 'A', C.g2], [CUT[0], CUT[1], '別の対象', C.blue], [CUT[1], CYC, 'A', C.g2]], u);
  return away ? 'CUTAWAY' : 'SHOT A';
});
