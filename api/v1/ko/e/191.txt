// 무엇이 일어나는가: 점프의 정점에서 시간이 거의 멈추고, 그동안 카메라가 인물 주위를 돈다.
// 동작 사양:
//   - 영상 시간: 0~1.5초는 정상 속도, 1.5초부터 3.3초까지는 0.1×(1.8초 동안 영상은 0.18초만 진행), 그 뒤 다시 정상(영상 시간 = u - 1.62)
//   - 피사체: 9m 거리의 인물이 영상 시간 0.6~2.6초에 포물선으로 점프(정점 1.1m, 두 팔을 든다). 느린 구간에서는 정점 부근(45~54% 지점)에 떠 있는 것처럼 보인다. 나뭇잎 9장이 같은 영상 시간으로 떨어진다
//   - 카메라: 느린 구간 동안 인물을 중심으로 반지름 6m의 원을 따라 -0.6rad에서 +0.6rad(약 69°)까지 이동. 3차 ease-in-out(cubic-bezier(0.65,0,0.35,1)에 가까움). 항상 중심을 향하고 높이 1.6m, 피치 -0.05rad
//   - 다음 4.7초에는 반대 방향(+0.6 → -0.6rad)으로 돌기 때문에 9.4초 루프가 이음매 없이 이어진다(#030 오비트는 시간을 멈추지 않는다)
//   - 지면에 반지름 1.3m 점선 원, 10m 거리에 나무가 원형으로 늘어서 있다. 오른쪽 위에 "×1.0" → "BULLET ×0.1" → "×1.0" 표시
// 쓰임새: 결정적인 순간을 입체적으로 보여 줄 때, 액션 장면의 하이라이트로.
// 태그: bullet time, time slice, frozen moment, orbit, slow motion, matrix, effect
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 견본: https://showheyohtaki.github.io/motion-prompt/#191
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 23
// 23 バレットタイム: 跳躍の頂点で時間がほぼ止まり、その間にカメラが人物の周りを回り込む（#030 オービットは時間が止まらない）
CELLS[22] = shot((k, w, h, u, cyc) => {
  const T0 = 1.5, T1 = 3.3, SLOW = 0.1;
  const tj = u < T0 ? u : u < T1 ? T0 + (u - T0) * SLOW : u - (T1 - T0) * (1 - SLOW);   // 実時間→映像時間
  const q = P(tj, 0.6, 2.6), e = eIO(P(u, T0, T1));
  const a = cyc % 2 === 0 ? lerp(-0.6, 0.6, e) : lerp(0.6, -0.6, e), R = 6, P0 = [0, 0, 9];
  const c = cam({ x: P0[0] + Math.sin(a) * R, z: P0[2] - Math.cos(a) * R, yaw: -a, y: 1.6, pitch: -0.05 });
  world(k, w, h, c, {
    person: { z: 9, y: jumpY(q), armUp: q > 0 && q < 1, face: a }, ring: [0, 9, 10], trees: false, extra: leaves(tj, 1.5).map(l => [l[0], l[1], l[2] + 3, l[3]]),
    after: (kk, cc) => { kk.strokeStyle = C.blueM; kk.lineWidth = 2; kk.setLineDash([5, 5]); kk.beginPath(); for (let i = 0; i <= 48; i++) { const b = i / 48 * Math.PI * 2; const qq = proj(cc, Math.sin(b) * 1.3, 0, 9 + Math.cos(b) * 1.3); i ? kk.lineTo(qq.x, qq.y) : kk.moveTo(qq.x, qq.y); } kk.stroke(); kk.setLineDash([]); }
  });
  return u >= T0 && u < T1 ? `BULLET ×${SLOW.toFixed(1)}` : '×1.0';
});
