// 무엇이 일어나는가: 구불구불 걷는 인물을 같은 경로로 몇 미터 뒤에서 따라간다. 인물은 뒷모습으로 화면 중앙 부근에 머문다.
// 동작 사양:
//   - 경로: 인물은 곡선 x = 1.8·sin(2.2s), 깊이 z = 4 + 9s(s는 0에서 1)를 따라 4m에서 13m 거리까지 걷는다
//   - 카메라: 같은 곡선의 s-0.4 지점(약 3.6~3.9m 뒤)을 따라가며 항상 인물을 향한다. yaw = atan2(person x - camera x, person z - camera z). 높이 1.5m
//   - 타이밍: 0.3초부터 4.2초까지 3.9초. 3차 ease-in-out(cubic-bezier(0.65,0,0.35,1)에 가까움). 다리와 팔은 sin(s×30)×0.42rad로 흔들린다
//   - 인물은 뒷모습으로 화면 중앙 부근에 머물고, 길가의 말뚝과 바위가 전경을 스쳐 지나간다(#029 트래킹 샷은 옆에서 나란히 따라간다)
//   - 복귀: 마지막 0.5초 동안 시작 상태로 크로스페이드(1회 4.7초). 오른쪽 위에 인물까지의 거리 표시(FOLLOW 3.6–3.9m)
// 쓰임새: 캐릭터와 함께 장소에 들어갈 때, 게임 같은 3인칭 시점이 필요할 때.
// 태그: follow shot, follow, behind, third person, trail, walk, camera move
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera2 -> https://bbq-man.github.io/motion-prompt-kor/api/v1/kit/camera2.js
// 움직이는 견본: https://bbq-man.github.io/motion-prompt-kor/#174
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 06
// 06 フォローショット: 蛇行して歩く人物の後ろを、少し遅れて同じ道筋でついていく（#029 トラッキングは真横に並ぶ）
CELLS[5] = shot(camCell((k, w, h, p) => {
  const path = s => [1.8 * Math.sin(s * 2.2), 4 + s * 9];
  const [px, pz] = path(p), [cx, cz] = path(p - 0.4);
  world(k, w, h, cam({ x: cx, z: cz, y: 1.5, yaw: Math.atan2(px - cx, pz - cz) }), { person: { x: px, z: pz, walk: p * 30 }, fg: [[-2.4, 7], [2.6, 9.5, 'rock'], [-1.5, 12]] });
}, p => `FOLLOW ${Math.hypot(1.8 * Math.sin(p * 2.2) - 1.8 * Math.sin((p - 0.4) * 2.2), 3.6).toFixed(1)}m`, 0.3, 4.2));
