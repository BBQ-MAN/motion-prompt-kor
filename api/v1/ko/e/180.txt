// 오버 더 숄더 샷 / Over-the-shoulder
// 팩: camera2 (카메라 워크와 화면 전환 2) · element 12 · 카테고리: 앵글·구도
// 무엇이 일어나는가: 한 사람의 뒤통수와 어깨가 화면 가장자리에 걸리고 그 너머로 상대가 보인다. 전경은 흐리고 피사체는 선명하다.
// 동작 사양:
//   - 구도: 앞사람의 뒤통수와 어깨(회색, 왼쪽 0.62m, 1.15m 거리)가 왼쪽 가장자리를 채우고, 어깨 너머로 상대(파랑, 오른쪽 0.32m, 3.1m 거리)가 보인다
//   - 초점: 앞쪽 어깨는 2.6px 블러, 상대는 선명하고 가슴 위로 잡힌다
//   - 카메라: 높이 1.55m, 요 +0.05rad. 0.5초부터 3.4초까지 0m → 0.35m 천천히 푸시 인(3차 ease-in-out(cubic-bezier(0.65,0,0.35,1)에 가까움))
//   - 상대는 말하는 것처럼 팔다리를 0.35·sin(u×5)rad로 흔든다
//   - 복귀: 3.4~4.2초 정지 후 마지막 0.5초 동안 시작 상태로 크로스페이드. 오른쪽 위에 "OTS" 표시
// 쓰임새: 대화에서 누가 누구를 마주하고 있는지 보여 주고 상대의 표정에 집중시킬 때.
// 태그: over-the-shoulder, ots, dialogue, conversation, shoulder, two shot, angle
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera2 -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera2.js
// 움직이는 견본: https://showheyohtaki.github.io/motion-prompt/#180
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 12
// 12 オーバーザショルダー: 手前の人物の肩と後頭部を画面の端に入れ、肩越しに相手を撮る。手前はぼけ、相手にピント
CELLS[11] = shot(camCell((k, w, h, p, u) => {
  world(k, w, h, cam({ z: lerp(0, 0.35, p), y: 1.55, yaw: 0.05 }), {
    person: { x: 0.32, z: 3.1, walk: 0.35 * Math.sin(u * 5) }, blurFg: 2.6,
    extra: [[-0.62, 0, 1.15, (kk) => { kk.fillStyle = C.g4; kk.beginPath(); kk.arc(0, 1.63, 0.17, 0, 7); kk.fill(); rr(kk, -0.34, 0.9, 0.68, 0.6, 0.14); kk.fill(); }, true]]
  });
}, p => 'OTS'));
