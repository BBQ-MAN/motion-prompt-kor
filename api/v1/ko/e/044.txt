// 크로스 디졸브 / Cross dissolve
// 팩: camera (카메라 무빙과 화면 전환) · element 20 · 카테고리: 화면 전환(트랜지션)
// 무엇이 일어나는가: 현재 화면 위에 다음 화면을 겹치고 불투명도를 올려 교체한다. 중간에는 두 화면이 겹쳐 비친다.
// 동작 사양:
//   - 연결: 1.5초부터 3.0초까지 1.5초. 다음 화면의 불투명도를 0 → 100%
//   - 이징: 2차 ease-in-out(cubic-bezier(0.45,0,0.55,1) 상당). 중간인 2.25초에 50%
//   - 앞 화면은 불투명한 채로 아래에 두고 그 위에 다음 화면을 겹친다(앞 화면을 먼저 페이드 아웃하지 않는다)
//   - 카메라: 두 화면 모두 고정(A는 높이 1.4m, B는 높이 1.6m에 피치 +0.1rad). 피사체도 움직이지 않는다
//   - 0~1.5초는 앞 화면만, 3.0~4.7초는 다음 화면만 보인다
//   - 4.7초마다 A→B와 B→A를 번갈아 실행(왕복 9.4초). 오른쪽 위에 “A → B” / “B → A” 표시
// 쓰임새: 시간의 흐름이나 장소 이동을 부드럽게 전하거나, 회상으로 들어갈 때.
// 태그: cross dissolve, dissolve, crossfade, fade, opacity, blend, transition
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera -> https://bbq-man.github.io/motion-prompt-kor/api/v1/kit/camera.js
// 움직이는 견본: https://bbq-man.github.io/motion-prompt-kor/#044
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 20
// 20 クロスディゾルブ
CELLS[19] = shot(abCell((k, w, h, u, A, B) => blend(k, kk => A(kk, w, h), kk => B(kk, w, h), eIOs(P(u, 1.5, 3.0)))));
