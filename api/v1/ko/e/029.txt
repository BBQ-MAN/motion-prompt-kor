// 트래킹 숏 / Tracking shot
// 팩: camera (카메라 무빙과 화면 전환) · element 05 · 카테고리: 카메라 움직임
// 무엇이 일어나는가: 걷는 인물과 같은 속도로 카메라가 옆으로 나란히 이동한다. 인물은 화면 중앙에 머물고, 가까운 말뚝일수록 빠르게 뒤로 흐른다.
// 동작 사양:
//   - 카메라: 오른쪽으로 등속 1.7m/s로 이동(x = -4.0m → +4.0m, 4.7초). 높이 1.3m, 방향은 정면 그대로. 이징 없음
//   - 피사체: 인물은 카메라와 같은 x를 걷는다(깊이 7.5m). 화면 중앙에서 벗어나지 않는다. 팔다리는 sin(u×7)×0.42rad로 흔든다
//   - 패럴랙스: 깊이 4m에 1.6m 간격으로 늘어선 말뚝이 가장 빠르게 왼쪽으로 흐르고, 나무, 건물(48m 앞) 순으로 느려진다. 산은 거의 움직이지 않는다
//   - 오른쪽 위에 “→ 1.7m/s” 표시
//   - 반복: 4.7초마다 시작 위치로 돌아간다(말뚝과 지면 격자는 이음매가 맞지만, 배경의 건물과 나무는 위치가 튄다)
// 쓰임새: 걷거나 뛰는 피사체를 따라가며 이동감을 유지한 채 동작을 보여 줄 때.
// 태그: tracking, tracking shot, follow, truck, lateral, sideways, parallax, walk
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera -> https://bbq-man.github.io/motion-prompt-kor/api/v1/kit/camera.js
// 움직이는 견본: https://bbq-man.github.io/motion-prompt-kor/#029
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 05
// 05 トラッキング: 人物と並んで横移動（手前ほど速く流れる）
CELLS[4] = shot((k, w, h, u) => {
  const x = (u - CYC / 2) * 1.7;
  const fgp = []; for (let i = -12; i <= 12; i++) fgp.push([i * 1.6, 4]);
  world(k, w, h, cam({ x, y: 1.3 }), { person: { x, z: 7.5, walk: u * 7 }, fg: fgp });
  return '→ 1.7m/s';
});
