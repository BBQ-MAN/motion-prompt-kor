// 점프 컷 / Jump cut
// 팩: camera (카메라 무빙과 화면 전환) · element 17 · 카테고리: 화면 전환(트랜지션)
// 무엇이 일어나는가: 카메라 위치와 화각은 그대로이고 인물의 위치와 시각만 튄다. 한 장면 안에서 시간을 생략하는 편집.
// 동작 사양:
//   - 연결: 효과 없이 바로 잇는 스트레이트 컷(0프레임). 5개 숏을 각 0.94초씩(4.7초 ÷ 5)
//   - 카메라: 모든 숏에서 위치와 화각이 같다(높이 1.4m, 정면). 배경은 1px도 움직이지 않는다
//   - 바뀌는 것: 인물(7m 앞)의 가로 위치가 -2.2m → 1.4m → -0.4m → 2.4m → 0.6m로 튄다. 2번째와 4번째 숏에서는 두 팔을 올린 자세
//   - 각 숏 안에서 인물은 움직이지 않는다(위치와 자세의 차이로만 건너뜀을 보여 준다)
//   - 오른쪽 위 시계: 10:02 → 10:17 → 10:41 → 11:06 → 11:30. 같은 장소에서 시간이 건너뛰었음을 보여 준다
//   - 5번째 숏에서 1번째 숏으로도 스트레이트 컷으로 돌아간다
// 쓰임새: 말이나 작업 사이의 공백을 줄여 템포를 높이거나, 시간 경과를 짧게 보여 줄 때.
// 태그: jump cut, cut, time skip, same framing, vlog, ellipsis, edit
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera -> https://bbq-man.github.io/motion-prompt-kor/api/v1/kit/camera.js
// 움직이는 견본: https://bbq-man.github.io/motion-prompt-kor/#041
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 17
// 17 ジャンプカット（同じ画角で人物の位置と時刻だけ飛ぶ）
CELLS[16] = shot((k, w, h, u) => {
  const shots = [[-2.2, 0], [1.4, 1], [-0.4, 0], [2.4, 1], [0.6, 0]];
  const times = ['10:02', '10:17', '10:41', '11:06', '11:30'];
  const i = Math.min(4, Math.floor(u / (CYC / 5)));
  const [x, arm] = shots[i];
  world(k, w, h, cam({ y: 1.4 }), { person: { x, z: 7, armUp: !!arm } });
  return times[i];
});
