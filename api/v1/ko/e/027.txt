// 동작 사양:
//   - 카메라: 앞(깊이 방향)으로 0m → 5.8m 전진. 높이 1.5m, 방향과 초점 거리(330px, 24mm로 표시)는 고정
//   - 시간: 0.5초부터 3.4초까지 2.9초. 3차 ease-in-out(cubic-bezier(0.65,0,0.35,1) 상당)
//   - 피사체: 인물은 8m 앞에서 움직이지 않는다. 거리가 8m → 2.2m가 되어 화면상 크기는 약 3.6배
//   - 패럴랙스 있음: 앞쪽 말뚝(왼쪽 1.5m, 깊이 3.6m)과 바위(오른쪽 1.6m, 깊이 4.8m)는 도중에 화면 밖으로 빠진다. 120m 이상 떨어진 산은 크기가 거의 그대로
//   - 복귀: 3.4~4.2초는 정지, 마지막 0.5초 동안 시작 상태로 크로스페이드(1회 4.7초)
//   - 오른쪽 위 표시는 24mm에서 변하지 않는다(04 줌 인과의 차이)
// 쓰임새: 공간의 깊이감을 살리면서 인물이나 한 지점으로 다가갈 때.
// 태그: dolly, dolly in, push in, track in, move forward, parallax, camera move
