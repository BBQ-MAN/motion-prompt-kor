// 동작 사양:
//   - 카메라: 위치 고정(높이 1.4m), 피치만 -0.06rad → +0.36rad(-3° → +21°, 총 약 24°)
//   - 시간: 0.5초부터 3.4초까지 2.9초. 3차 ease-in-out(cubic-bezier(0.65,0,0.35,1) 상당)
//   - 피사체: 인물은 7m 앞에서 움직이지 않는다. 그 뒤 26m 거리에 높이 9.5m의 탑(꼭대기 안테나는 11.8m까지)
//   - 화면에서는 전체가 위에서 아래로 흐르며, 인물은 아래로 빠져나가고 탑 윗부분과 꼭대기 안테나가 들어온다
//   - 복귀: 3.4~4.2초는 정지, 마지막 0.5초 동안 시작 상태로 크로스페이드(1회 4.7초)
//   - 오른쪽 위에 각도를 정수 단위 도로 표시(-3° → +21°)
// 쓰임새: 건물이나 인물의 높이와 크기를 보여 줄 때.
// 태그: tilt, tilt up, pitch, vertical, look up, camera move
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera -> https://bbq-man.github.io/motion-prompt-kor/api/v1/kit/camera.js
// 움직이는 견본: https://bbq-man.github.io/motion-prompt-kor/#026

// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.

  p => `${Math.round(lerp(-0.06, 0.36, p) * 57.3)}°`.replace(/^(\d)/, '+$1')));
