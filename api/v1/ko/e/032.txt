// 돌리 줌(버티고 효과) / Dolly zoom (Vertigo)
// 팩: camera (카메라 무빙과 화면 전환) · element 08 · 카테고리: 카메라 움직임
// 무엇이 일어나는가: 카메라를 뒤로 빼면서 같은 비율로 줌 인한다. 인물 크기는 변하지 않고 배경만 다가온다.
// 동작 사양:
//   - 카메라: 인물(8m 앞)까지의 거리 d를 3.2m → 8m로 넓힌다(4.8m 후퇴). 높이 1.3m
//   - 초점 거리: f = 330 × d/8 px, 즉 132px → 330px(10mm → 24mm로 표시). 거리와 초점 거리의 비를 일정하게 유지
//   - 시간: 0.5초부터 3.4초까지 2.9초. 3차 ease-in-out(cubic-bezier(0.65,0,0.35,1) 상당)
//   - 피사체: 인물은 움직이지 않고 화면상 높이도 일정. 머리(1.8m)와 발밑에 폭 160px의 파란 점선을 그어 크기가 변하지 않음을 보여 준다
//   - 배경: 건물(48m 앞)은 약 2.2배, 산은 약 2.4배로 커져 인물 뒤로 다가온다. 인물보다 앞쪽의 지면은 반대로 줄어든다
//   - 복귀: 3.4~4.2초는 정지, 마지막 0.5초 동안 시작 상태로 크로스페이드(1회 4.7초)
// 쓰임새: 무언가를 깨닫는 순간이나 불안, 충격을 영상으로 표현할 때.
// 태그: dolly zoom, vertigo, zolly, push pull, background stretch, unease, camera move
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/kit/camera.js
// 움직이는 견본: https://showheyohtaki.github.io/motion-prompt/#032
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 08
// 08 ドリーズーム: 人物の大きさは一定、背景だけ伸び縮み
CELLS[7] = shot(camCell((k, w, h, p) => {
  const d = lerp(3.2, 8, p), f = F0 * d / 8 * 1.0;
  const c = cam({ z: 8 - d, f, y: 1.3 });
  world(k, w, h, c, {
    person: { z: 8 }, trees: true,
    after: (kk, cc) => { const top = proj(cc, 0, 1.8, 8).y, bot = proj(cc, 0, 0, 8).y; kk.strokeStyle = C.blue; kk.lineWidth = 1.6; kk.setLineDash([6, 5]); kk.beginPath(); kk.moveTo(-80, top); kk.lineTo(80, top); kk.moveTo(-80, bot); kk.lineTo(80, bot); kk.stroke(); kk.setLineDash([]); }
  });
}, p => mm(F0 * lerp(3.2, 8, p) / 8)));
