// 매치 컷 / Match cut
// 팩: camera (카메라 무빙과 화면 전환) · element 18 · 카테고리: 화면 전환(트랜지션)
// 무엇이 일어나는가: 위로 던진 공이 다음 숏에서 같은 위치, 같은 크기의 해가 된다. 모양을 맞춰 다른 장면으로 잇는다.
// 동작 사양:
//   - 연결: 2.3초에 스트레이트 컷(0프레임). 컷 앞뒤로 파란 원의 위치(중심에서 오른쪽 120px, 위 46px)와 반지름 17px를 일치시킨다
//   - 앞 숏(0~2.3초): 고정 카메라(높이 1.4m). 인물(왼쪽 1.2m, 깊이 7m)이 0.5초부터 공을 던진다. 3차 ease-out(cubic-bezier(0.33,1,0.68,1) 상당)
//   - 공: 인물 머리 위(높이 2.3m)에서 일치 지점으로 이동. 반지름 5px → 17px, 도중에 최대 30px 위로 부푼 호를 그린다
//   - 뒤 숏(2.3~4.7초): 다른 장소(건물 없음, 높이 1.2m). 같은 위치의 파란 원이 해가 되어 2.4초 동안 14px 내려간다
//   - 마커: 반지름 26px의 파란 점선 원이 컷 앞뒤 0.7초 안에서 페이드 인/아웃된다
//   - 오른쪽 위에 “SHOT 1” → “SHOT 2” 표시. 4.7초에 SHOT 1로 스트레이트 컷으로 돌아간다
// 쓰임새: 시간이나 장소가 멀리 떨어진 두 장면을 공통된 모양이나 동작으로 이을 때.
// 태그: match cut, graphic match, shape match, cut, transition, edit
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera -> https://bbq-man.github.io/motion-prompt-kor/api/v1/kit/camera.js
// 움직이는 견본: https://bbq-man.github.io/motion-prompt-kor/#042
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 18
// 18 マッチカット（投げたボール → 同じ位置・大きさの太陽）
CELLS[17] = shot((k, w, h, u) => {
  const cut = 2.3;
  const BX = 120, BY = -46, BR = 17;
  if (u < cut) {
    const q = eOut(P(u, 0.5, cut));
    world(k, w, h, cam({ y: 1.4 }), {
      person: { x: -1.2, z: 7, armUp: q > 0.05 }, sun: null,
      after: (kk, cc) => { const s = proj(cc, -1.2, 2.3, 7); const x = lerp(s.x, BX, q), y = lerp(s.y, BY, q) - Math.sin(q * Math.PI) * 30, r = lerp(5, BR, q); kk.fillStyle = C.blue; kk.beginPath(); kk.arc(x, y, r, 0, 7); kk.fill(); }
    });
  } else {
    const q = P(u, cut, CYC);
    world(k, w, h, cam({ y: 1.2 }), {
      buildings: false, sun: null, trees: true,
      after: (kk) => { kk.fillStyle = C.blue; kk.beginPath(); kk.arc(BX, BY + q * 14, BR, 0, 7); kk.fill(); }
    });
  }
  // 形がそろっていることを示す点線の円
  const g = Math.max(0, 1 - Math.abs(u - cut) / 0.7);
  if (g > 0) { k.save(); k.translate(w / 2, h / 2); k.globalAlpha = g; k.strokeStyle = C.blue; k.lineWidth = 2; k.setLineDash([5, 4]); k.beginPath(); k.arc(BX, BY + (u > cut ? P(u, cut, CYC) * 14 : 0), BR + 9, 0, 7); k.stroke(); k.restore(); }
  return u < cut ? 'SHOT 1' : 'SHOT 2';
});
