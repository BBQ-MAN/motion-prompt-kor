// 슬로모션 / Slow motion
// 팩: camera (카메라 무빙과 화면 전환) · element 13 · 카테고리: 촬영 기법과 시간 연출
// 무엇이 일어나는가: 고정 카메라 앞에서 인물이 천천히 뛰어올랐다 내려오고, 나뭇잎도 천천히 떨어진다. 동작 전체를 늘여서 보여 준다.
// 동작 사양:
//   - 카메라: 완전히 고정(높이 1.3m). 움직이는 것은 피사체뿐
//   - 피사체: 7m 앞의 인물이 한 번 점프하는 데 3.8초가 걸린다(0.5초~4.3초). 높이 = 4q(1-q)×1.1m인 포물선, 정점 1.1m. q는 시간에 대해 선형
//   - 공중에 있는 동안 두 팔을 올린다. 점프 전 0.5초와 착지 후 0.4초는 선 채로 있다
//   - 나뭇잎: 9장이 높이 3.4m에서 지면까지 4.7초 동안 회전하며 떨어진다. 위상을 1/9씩 어긋나게 해서 순환
//   - 오른쪽 위에 “120fps ×0.25” 표시(재생을 4배로 늘렸다는 설정)
//   - 정지와 크로스페이드 없음. 4.7초마다 이음매 없이 반복
// 쓰임새: 짧은 동작이나 표정을 찬찬히 보여 주거나, 감정의 절정을 강조할 때.
// 태그: slow motion, slow-mo, slomo, high frame rate, 120fps, time stretch, jump
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit camera -> https://bbq-man.github.io/motion-prompt-kor/api/v1/kit/camera.js
// 움직이는 견본: https://bbq-man.github.io/motion-prompt-kor/#037
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 13
// 13 スローモーション
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
