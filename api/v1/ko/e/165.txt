// 무엇이 일어나는가: 파란 섹션과 흰 섹션이 만나는 곳에서 겹쳐진 물결 두 개가 천천히 계속 일렁인다.
// 동작 사양:
//   - 511 × 168 뷰포트: 위는 파란 그라데이션 섹션(#3B64E8 → #8FA9F7), 아래는 흰 섹션, 경계에 물결 두 겹. 1루프 4.7초(팩 주기 9.4초에 2회).
//   - 뒤 물결(흰색, opacity 0.45): 중심 y = 100. 파장 260 px, 진폭 8 px 사인파와 파장 130 px, 진폭 4 px 사인파의 합.
//   - 앞 물결(흰색): 중심 y = 110. 파장 300 px/진폭 9 px에 파장 110 px/진폭 3.5 px를 더한다. 아래 흰 섹션과 이어진다.
//   - 위상 a = 2π·t/4.7일 때 뒤 물결은 a + 1과 −2a, 앞 물결은 −a와 2a + 0.5를 쓴다. 각 물결의 두 사인파가 반대 방향으로 흘러 모양이 계속 바뀌며, 4.7초마다 처음 모양으로 돌아온다.
// 쓰임새: 바다, 여름, 어린이 관련 사이트처럼 섹션 경계를 직선보다 부드럽게 보이고 싶을 때.
// 태그: shape-divider, wave, section-divider, svg, ambient, loop
// 크기: 539x208 px · 1주기: 9.4 s
// Needs: kit lp2 -> https://bbq-man.github.io/motion-prompt-kor/api/v1/kit/lp2.js
// 움직이는 견본: https://bbq-man.github.io/motion-prompt-kor/#165
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D(호출하는 쪽에서 지우기와 save/restore 완료), w·h = 크기, u = 초(0 이상 1주기 미만). u만으로 그림이 정해진다.
// 여기부터 요소의 코드. CELLS와 상수·보조 함수는 kit에 있다.

// @element 21
// 21 シェイプディバイダー（セクションの境目の波の形が、ゆっくりゆれ続ける）
CELLS[20] = (k, w, h, u) => {
  u = snapU(u);
  frame(k);
  const a = 2 * Math.PI * u / CYC;
  const wave = (base, A1, L1, p1, A2, L2, p2) => { k.beginPath(); k.moveTo(0, VH + 1); for (let x = 0; x <= VW + 4; x += 4) k.lineTo(x, base + A1 * Math.sin(2 * Math.PI * x / L1 + p1) + A2 * Math.sin(2 * Math.PI * x / L2 + p2)); k.lineTo(VW, VH + 1); k.closePath(); };
  view(k, () => {
    const g = k.createLinearGradient(0, 0, 0, 120); g.addColorStop(0, '#3B64E8'); g.addColorStop(1, '#8FA9F7'); k.fillStyle = g; k.fillRect(0, 0, VW, VH);
    k.fillStyle = 'rgba(255,255,255,.9)'; k.beginPath(); k.arc(430, 44, 22, 0, 7); k.fill();
    txt(k, '夏のキャンペーン', 34, 42, `800 22px ${JP}`, '#fff'); btn(k, 34, 56, 96, 24, '詳しく見る', '#fff', C.blue, 11);
    k.fillStyle = 'rgba(255,255,255,.45)'; wave(100, 8, 260, a + 1, 4, 130, -2 * a); k.fill();
    k.fillStyle = '#fff'; wave(110, 9, 300, -a, 3.5, 110, 2 * a + 0.5); k.fill();
    txt(k, 'おすすめプラン', 34, 146, `800 15px ${JP}`, C.ink); bars(k, 170, 140, 290, 1, C.faint, 6);
    bars(k, 34, 156, 200, 1, C.faint, 5);
  });
};
