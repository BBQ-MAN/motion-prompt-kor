// 동작 사양:
//   - 카메라: 위치 고정(높이 1.5m). 롤만 0 → 2π rad(360°). 화면 중앙을 축으로 화면 전체가 회전
//   - 타이밍: 0.5초부터 3.6초까지 3.1초. 3차 ease-in-out(cubic-bezier(0.65,0,0.35,1)에 가까움)
//   - 피사체: 인물은 7m 앞에 서 있다. 지평선, 건물, 인물이 모두 같은 각도로 돌고, 도는 동안 화면 네 귀퉁이에 흰 바탕이 보인다
//   - 정지: 3.6~4.2초. 한 바퀴 돈 화면은 시작 화면과 같으므로 마지막 0.5초의 크로스페이드는 보이지 않는다(1회 4.7초)
//   - 오른쪽 위에 각도 표시(↻ 0° → ↻ 360°)
// 쓰임새: 항공·드론 영상에 역동감을 더할 때, 어지러움이나 혼란을 표현할 때.
