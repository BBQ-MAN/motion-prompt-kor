# Motion Prompt

[English](README.md) | [日本語](README.ja.md) | **한국어**

> 이름 목록은 한국어, 영어, 일본어, 스페인어, 중국어(간체·번체) 6개 언어로 [`packs/`](packs/README.md)에 있습니다. 갤러리는 한국어, 영어, 일본어로 볼 수 있습니다.

AI에게 무언가를 만들어 달라고 할 때 쓰는 '이름'의 라이브러리입니다. 이름마다 움직이는 예시, 한 줄 설명, AI에게 요청하는 문장 예시가 붙어 있습니다. 지금은 모션 그래픽 동작(`motion`), 카메라 워크(`camera`), UI 컴포넌트 이름(`ui`), 랜딩 페이지·웹 연출(`lp`), 사진 표현·조명과 화풍(`photo`), 모션 그래픽 동작 2편(`motion2`), 랜딩 페이지·웹 연출 2편(`lp2`), 카메라 워크와 화면 전환 2편(`camera2`)의 8개 세트가 들어 있고, 세트마다 24개씩 모두 192개입니다. 같은 방식의 라이브러리를 자기 분야, 자기 언어로 만드는 프롬프트도 함께 들어 있습니다.

## 만든 이유

모션 그래픽과 카메라 워크의 이름을 정리한 짧은 영상을 몇 개 올렸더니, 며칠 동안 많은 댓글이 달렸습니다. 그중 하나는 요약하면 이런 내용이었습니다. 자신을 가로막고 있던 것은 상상력의 부족이 아니라, 이런 움직임을 뭐라고 부르는지 모른다는 점이었다고요.

그 댓글을 보고, 여러 언어로, 각 분야를 잘 아는 사람들이 AI를 잘 다루는 데 필요한 '공통 언어'를 둘러볼 수 있는 라이브러리로 정리해 준다면 정말 쓸모가 있겠다고 생각했습니다. 그래서 그것을 GitHub 저장소로 만들어 봤습니다.

하나의 스타일을 따라 하라고 내놓은 저장소가 아닙니다. 여기 있는 프롬프트와 지침으로 이런 모션 그래픽을 만들 수 있고, 같은 방식의 이름 예시를 자기 분야, 자기 언어, 원하는 스타일로 만들 수도 있는 곳으로 만들고 싶습니다.

이런 댓글도 있었습니다. "this is how you become a creative director". 맞는 말입니다. AI와 함께 좋은 작업을 하는 크리에이티브 디렉터가 세계 곳곳에 더 많아진다면 정말 멋진 일이라고 생각합니다.

목록마다 번호, 이름, 뜻, AI에게 요청하는 문장 예시가 한국어, 영어, 일본어, 스페인어, 중국어 간체, 중국어 번체로 정리되어 있습니다. 같은 이름이 [갤러리](https://showheyohtaki.github.io/motion-prompt/)에서 움직입니다.

팩마다 스타일이 다릅니다. motion과 motion2 팩은 짙은 남색 바탕에 4가지 색을 씁니다. camera와 camera2 팩은 밝은 회색 바탕에 파란색 하나입니다. ui 팩은 따뜻한 오프화이트 바탕에 검정과 파란색 하나를 쓰고, 커서가 닿으면 각 컴포넌트가 움직입니다. lp와 lp2 팩은 옅은 회색 책상 위에 흰 브라우저 창을 그리고, 포인트 컬러는 주홍색, 페이지 안의 이미지는 파란색입니다. photo 팩에는 공통 팔레트가 없습니다. 카드마다 그 장면의 색으로 그리고, 효과가 들어갔다가 다시 빠지므로 전후를 비교할 수 있습니다. 일부러 이렇게 했습니다. 팩이 맞춰야 하는 것은 이름이지, 정해진 스타일이 아닙니다.

## 세 가지 사용법

### 1. 라이브러리를 열고, 고르고, AI에게 보내기

Claude Code나 Codex에 `motion-prompt` 스킬을 설치하면, 요청만으로 이 갤러리가 열립니다. 이름이나 번호를 외울 필요는 없습니다. 무엇이라고 부르는지 모를 때 사전을 찾듯 라이브러리를 열어 달라고 하면 됩니다.

```sh
npx skills add showheyohtaki/motion-prompt
```

1. AI에게 요청합니다.
   ```text
   Open the motion-prompt library.
   ```
2. 브라우저에서 갤러리가 열립니다. 쓰고 싶은 예시의 '고르기'를 누릅니다. 몇 개든 고를 수 있습니다. 화면 아래 메모 칸에는 '오프닝 타이틀용'처럼 짧은 메모를 적을 수 있습니다.
3. 'AI에게 전달'를 누르면 고른 항목이 AI에게 전달됩니다. AI 화면으로 돌아가 원하는 작업을 말합니다.
   ```text
   Edit the opening of this video like this.
   ```

에이전트는 고른 항목만 사용합니다. 사양과 참고 코드를 가져와 프로젝트의 작업 방식에 맞게 영상이나 사이트에 넣습니다. '카메라 워크 보여 줘'처럼 종류를 말하면, 그 분야의 팩(2편이 있으면 1편과 2편 모두)만 걸러진 상태로 갤러리가 열립니다.

스킬이 없는 AI에게 요청할 때는 갤러리에서 고른 다음 화면 아래의 '고른 항목 복사'를 누르고, 그 텍스트를 채팅에 붙여 넣으세요. 예시와 사양의 URL이 들어 있습니다.

**번호를 알고 있다면** 갤러리를 거치지 않고 번호로 요청할 수 있습니다.

```text
Use the motion-prompt skill with #012 and #045 to make this product video look professional.
```

```text
Replace the part where the title appears with #005 from motion-prompt. Keep the length and the transitions before and after it.
```

```text
Turn the camera move in motion-prompt #032 into an English prompt for Veo. The subject is a coffee cup on a desk.
```

다른 설치 방법과 에이전트가 하는 일은 아래 [스킬 설명](#스킬-설명)에 있습니다.

### 2. 이름을 찾아서 AI에게 그대로 말하기

[목록](packs/README.md)이나 갤러리를 열어 머릿속에 있는 움직임을 찾고, 그 이름을 프롬프트에 넣습니다. 길이, 강도, 무엇이 움직이는지를 덧붙이면 원하는 결과에 더 가까워집니다.

```text
Bring the title in with a mask reveal from below, 0.6 s, each line slightly after the one before.
```

```text
Slow dolly in toward her face; move the camera, do not zoom.
```

이 방법은 아무것도 설치할 필요가 없습니다. 이름은 코딩 AI에도, 영상 생성 모델에도, 사람에게 보내는 브리프에도 쓸 수 있습니다.

[`make-your-own/`](make-your-own/README.md)에는 코딩 AI에 붙여 넣는 프롬프트, 영상을 렌더링하는 스크립트, 완성된 예시 2개(각각 HTML 소스, 영상 3개, 치트시트 이미지)가 들어 있습니다.

## 스킬 설명

Node.js 18 이상이 필요합니다.

### 설치

**프롬프트로 설치.** Claude Code나 Codex에 다음 내용을 붙여 넣습니다.

```text
Read https://github.com/showheyohtaki/motion-prompt and install the motion-prompt skill in this environment. When it is installed, tell me how to use it in three lines.
```

**명령어로 설치.** `skills` 설치 도구를 사용합니다. Claude Code, Codex 등 Agent Skills를 읽는 에이전트에서 쓸 수 있습니다.

```sh
npx skills add showheyohtaki/motion-prompt
```

**Claude Code 플러그인으로 설치.**

```text
/plugin marketplace add showheyohtaki/motion-prompt
/plugin install motion-prompt@motion-prompt
```

**직접 복사.** `skills/motion-prompt` 폴더를 다음 중 한 곳에 복사합니다.

| 위치 | 적용 범위 |
|---|---|
| `~/.claude/skills/` | Claude Code, 모든 프로젝트 |
| `~/.agents/skills/` | Codex 등, 모든 프로젝트 |
| 프로젝트 안의 `.claude/skills/` | Claude Code, 해당 프로젝트만 |
| 프로젝트 안의 `.agents/skills/` | Codex 등, 해당 프로젝트만 |

### 에이전트용 설치 절차

이 절은 '프롬프트로 설치'의 프롬프트를 받은 AI 에이전트를 위한 절차입니다.

1. `node --version`으로 Node.js 18 이상을 쓸 수 있는지 확인합니다.
2. 사용자의 프로젝트 폴더에서 아래 명령을 실행합니다. 어느 에이전트에 설치할지 물으면 지금 실행 중인 자신을 고릅니다.
   ```sh
   npx skills add showheyohtaki/motion-prompt -y
   ```
3. 2단계를 쓸 수 없으면 저장소를 받아 폴더를 복사합니다. Claude Code라면 `.claude/skills/`에, 그 밖의 에이전트라면 `.agents/skills/`에 복사합니다(모든 프로젝트에서 쓰려면 `~/.claude/skills/` 또는 `~/.agents/skills/`).
   ```sh
   git clone --depth 1 https://github.com/showheyohtaki/motion-prompt.git /tmp/motion-prompt
   mkdir -p .claude/skills
   cp -R /tmp/motion-prompt/skills/motion-prompt .claude/skills/
   ```
4. 설치를 확인합니다. `<skill-dir>`은 스킬이 설치된 경로(`SKILL.md`가 있는 폴더)로 바꿉니다. 데이터 출처와 요소 개수가 출력되면 성공입니다.
   ```sh
   node <skill-dir>/scripts/motion-prompt.mjs info
   ```
   종료 코드 3은 데이터 출처에 접속하지 못했다는 뜻입니다. 네트워크 권한을 받은 뒤 다시 실행하세요.
5. `<skill-dir>/SKILL.md`를 읽고, 사용자에게 스킬 사용법을 세 줄로 알려 줍니다. 예:
   - "motion-prompt 라이브러리 열어 줘"라고 하면 갤러리가 열립니다. 원하는 항목의 '고르기'를 누른 다음 'AI에게 전달'를 누르세요.
   - 그다음 "이 영상의 오프닝을 이런 느낌으로 편집해 줘"처럼 원하는 작업을 말하세요.
   - 번호를 알고 있다면 "#012와 #045를 써 줘"처럼 바로 요청할 수도 있습니다.

기존 설정 파일이나 다른 스킬은 변경하지 마세요.

### 에이전트가 하는 일

- 라이브러리를 요청하면 브라우저에서 갤러리를 열고, 사용자가 고른 뒤 'AI에게 전달'를 누를 때까지 기다립니다(최대 15분).
- 프로젝트가 영상을 만드는 방식을 파악합니다. Canvas, Remotion, CSS, After Effects, 또는 영상 생성 모델용 프롬프트 등입니다.
- 사용자가 고른 항목이나 지정한 번호만 쓰고, 그 밖의 것은 쓰지 않습니다. 아무것도 고르지 않았다면 갤러리를 열어 보라고 권하고, 대신 골라 달라고 하면 장면마다 카탈로그를 검색해 고릅니다.
- 그 움직임을 프로젝트 안에서 다시 구현합니다. 타이밍, 이징, 수치는 공개된 그대로 유지하고, 텍스트, 색, 이미지는 사용자의 것으로 바꿉니다.
- 답변 끝에 사용한 번호, 각각 들어간 장면, 바꾼 점, 각 예시의 링크를 목록으로 정리합니다.

### 작동 방식

- 요소 하나는 함수 하나, `cells[i](ctx, w, h, u)`입니다. `ctx`는 Canvas 2D 컨텍스트, `w`와 `h`는 카드 크기, `u`는 한 주기 안에서의 시간(초)입니다.
- 그림은 `u`로만 결정됩니다. 함수는 그릴 때 시계를 읽거나 난수를 쓰지 않으므로, 실시간 재생과 프레임 단위 렌더링의 결과가 같습니다.
- 색, 크기, 주기 길이, 공통 헬퍼 함수는 팩마다 'kit'에 모여 있습니다. 요소를 쓰려면 해당 팩의 kit이 필요합니다.
- 외부 라이브러리는 쓰지 않습니다.

스킬은 세 파일로 이루어져 있습니다. 지침(`SKILL.md`), 영상 프로젝트 종류별로 요소를 옮기는 방법을 정리한 문서(`references/porting.md`), 요소를 조회하는 Node 스크립트(`scripts/motion-prompt.mjs`, 표준 라이브러리만 사용)입니다.

| 명령어 | 하는 일 |
|---|---|
| `pick` / `pick --pack camera` | 갤러리를 열고, 'AI에게 전달'로 들어온 내용(번호, 이름, 사양, 메모)을 출력합니다. 최대 15분 기다립니다 |
| `search typewriter text` / `search 文字 登場` | 장면에 맞는 요소를 찾습니다(영어 또는 일본어 단어) |
| `list` / `list --pack motion` | 전체 팩 개요, 또는 한 팩의 요소 전체 목록 |
| `get 12 #045` | 해당 번호의 사양과 코드를 차례로 출력합니다(한 번에 최대 8개) |
| `kit motion` | 팩의 공통 코드 |
| `prompt 12` | 요소의 복사용 프롬프트 |
| `info` | 데이터 출처, 데이터 양, 캐시 위치를 보여 줍니다 |

스크립트는 아래의 텍스트 파일을 GET 요청으로 가져오기만 합니다. 프로젝트의 내용은 어디에도 업로드하지 않습니다. `pick`은 사용자 컴퓨터(127.0.0.1)에 임시 수신 창구를 열고, 갤러리의 'AI에게 전달'가 보내는 번호와 메모만 받습니다.

1. `https://showheyohtaki.github.io/motion-prompt/api/v1/`
2. 1에 접속할 수 없을 때: `https://raw.githubusercontent.com/showheyohtaki/motion-prompt/main/api/v1/`

| 파일 | 내용 |
|---|---|
| `catalog.json` | 버전, 개수, 팩, 모든 요소의 이름, 뜻, 요약, 사양, 태그 |
| `{ja,en,ko}/catalog.tsv` | 탭으로 구분한 텍스트 색인(id, pack, category, title, tags, summary) |
| `{ja,en,ko}/e/{id}.txt` | 요소 하나: 저작권 표시 줄, 무엇을 보여 주는지, 사양, 코드 |
| `{ja,en,ko}/p/{id}.txt` | 요소 하나의 복사용 프롬프트 |
| `kit/{pack}.js` | 팩의 공통 코드 |

이 저장소 전체를 clone하면 CLI가 로컬의 `api/v1`을 먼저 읽으므로 네트워크가 필요 없습니다. 내려받은 데이터는 디스크에 저장되고, 출처에 접속할 수 없을 때는 저장된 사본을 씁니다.

| 환경 변수 | 기본값 |
|---|---|
| `MOTION_PROMPT_BASE` | 기본 출처 대신 읽을 곳. 로컬 폴더나 URL, 쉼표로 구분해 여러 개 지정 가능 |
| `MOTION_PROMPT_CACHE` | 내려받은 데이터를 저장할 곳. `~/.cache/motion-prompt`, 홈 폴더가 읽기 전용이면 시스템 임시 폴더 |
| `MOTION_PROMPT_TTL` | 저장된 카탈로그를 신뢰하는 시간(초). `21600`(6시간) |

### 갤러리를 직접 실행하기

```sh
git clone https://github.com/showheyohtaki/motion-prompt.git
cd motion-prompt
python3 -m http.server 8000
```

`http://localhost:8000/`을 열면 갤러리(`index.html`)가 보입니다. clone한 저장소에서는 `node skills/motion-prompt/scripts/motion-prompt.mjs pick --local`로 로컬 갤러리를 열어 항목을 고를 수 있습니다. 파일 형식은 [FORMAT.md](FORMAT.md)에 설명되어 있습니다.
